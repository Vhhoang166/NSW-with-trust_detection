# Archive

This folder keeps older or duplicate project artifacts without leaving them in the repository root.

## Contents

- `legacy_400_round_source/` - duplicate root-level source files from the older 400-round all-approach runner. The same files also appear in `output_400_rounds/source_files/` as provenance for that run.
- `root_duplicate_outputs/` - duplicate root-level CSV summaries that also exist in `output_400_rounds/`.

These files are kept for traceability. They are not the current maintained implementation path.
